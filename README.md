# Dns_changer
RU: Легкая утилита на Python для быстрой смены DNS-сервера (Google, Cloudflare, Quad9) в Windows в один клик. Автоматически запрашивает права администратора и очищает кэш сети. EN: A lightweight Python utility to change Windows DNS servers (Google, Cloudflare, Quad9) in one click. Automatically requests admin rights and flushes DNS cache.
